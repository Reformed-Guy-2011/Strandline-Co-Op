# StrandLine - Co-Op

A work-in-progress, open-world Co-Op physics sandbox zombie shooter

--Project Details--

**Engine:** Unreal Engine 5.8

**Platform:** Linux and Windows 11/10

---

Completed Systems

**Steam Server Browser:** server hosting, server joining, and server browser interface.

**Inventory & Item System:** Network-replicated inventory with item data and equipment slots.

**Settings Menu:** with graphics presets, resolution, and audio.

**AI & Combat Systems:** Enemy mob behaviors, agro states, and multiplayer pathfinding.

**Network Replication:** Complete multi-client sync across UI, player states, and movement.

---

In Active Development

**Character Customization:** Dynamic character model changer.

**Open-World Map:** Foundational persistent landscape and world partition setup.

**Boss Encounters:** Multi-phase boss mechanics and unique telegraph attacks.

**Cars:** Drivable cars with destruction physics.

**Biomes:** Multiple Biomes with difrent envirements and weather.

**Lua Based Zombie system:** Write the zombie spawner and zombie into Lua.
